# 灰度发布复盘

风格画廊的固定案例：同一条发布流水线、同一组指标、同一份遗留清单。

```mermaid
flowchart LR
  A([需求冻结]) --> B[灰度 5%]
  B --> C{错误率 < 1%?}
  C -- 是 --> D[扩量 50%]
  C -- 否 --> E[自动回滚]
  D --> F[(发布台账)]
  F --> G([复盘归档])
```
