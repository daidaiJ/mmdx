# Scenario guide (statechart)

Draw the **change of situation** in an incident, an approval, or a release as a statechart: states named for what the reader can see, arrows written as the reader's actions, risky states marked separately. The rules live in [§1a-2 of the mmdx skill](../../skill/SKILL.md).

The chart is mmdx's own loop — "want a diagram → check the environment → pick the shape → cut before drawing → render → check the image → hand over" — with two fallbacks (no browser found, render failed) and two marked states (`risk` marks where it breaks, `path` marks the shortest path).

## Paper stock (`--tone paper`)

For retros, review pages, and `a4` printing: `#FBF7EC` paper, warm grey rules, desaturated fills.

![Scenario guide · paper](scenario-paper.png)

## iPhone interface (`-t ios`)

For product UI docs and anything that should read as a system screenshot: grouped grey background, translucent white cards, system colours.

![Scenario guide · iOS](scenario-ios.png)

## Reproduce

```bash
mmdx examples/gallery/scenario.md --tone paper --preset a4 --title "mmdx 的使用回路" --json --quiet
mmdx examples/gallery/scenario.md -t ios --preset column --title "mmdx 的使用回路" --json --quiet
```

Source: [examples/gallery/scenario.md](../../examples/gallery/scenario.md); both images are generated by `scripts/make-gallery.ts`.
